# DN Studios — Ultra Luxury Portfolio

This version is built from the previous portfolio as the visual reference and expands it into a premium studio archive.

## Included
- Devam Namera founder cover with the supplied photo.
- DN Studios logo used as the primary brand mark.
- 15 project entries with local project visuals in `public/projects/`.
- Clickable project cards that open a full-screen case dossier.
- Clickable service disciplines:
  - Web Development
  - Mobile Applications
  - Web Applications
  - E-Commerce
  - PWA / Systems
  - Custom Software
- Each service opens its own premium dossier with deliverables, stack and featured work.
- Responsive mobile layout.
- GSAP intro motion and restrained luxury motion system.

## Run in PowerShell

```powershell
cd "C:\path\to\devam-premium-portfolio"
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```powershell
npm install
npm run build
npm run start
```
